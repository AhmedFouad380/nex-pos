# تصميمات الفواتير

شكل الفاتورة والإيصال المطبوع.

## إعداد تصميم
![إعداد تصميم فاتورة](/guide/img/printing-invoice-layouts.jpg)

1. اضغط **إضافة** واكتب **الاسم** واختر **الورق**: A4 أو A5 للفواتير الكاملة، أو حراري 80مم أو 58مم لإيصالات الكاشير.
2. **الافتراضي لنوع الورق ده**: ليُستخدم تلقائيًا عند الطباعة على هذا المقاس.
3. **ما يظهر في الطباعة**: اختر العناصر المطبوعة: اللوجو، واسم النشاط، واسم الفرع، وبيانات العميل وتليفونه، والرقم الضريبي، وكود الصنف، ورصيد العميل السابق، والمدفوعات، وباركود رقم الفاتورة، والمبلغ بالحروف (تفقيط).
4. **رأس وتذييل الصفحة**: **نص تحت اسم النشاط**، و**نص التذييل** مثل "شكرًا لزيارتكم" أو سياسة الاسترجاع.
5. **العناوين**: لتغيير مسميات الفاتورة، مثل "فاتورة ضريبية". اتركه فارغًا لاستخدام العنوان الافتراضي.
6. اضغط **معاينة** لرؤية الشكل قبل الحفظ.

> يمكن تحديد تصميم مختلف لكل فرع من صفحة **الفروع** (قالب الفاتورة وقالب الإيصال).
