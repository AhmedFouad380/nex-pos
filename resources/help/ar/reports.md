# التقارير

اختر الفترة والفرع والمرشحات أعلى التقرير، ثم اطبعه أو صدّره باستخدام **تصدير إلى Excel**.

![تقرير المبيعات والأرباح](/guide/img/reports-sales.jpg)

| التقرير | ما يعرضه |
|---|---|
| المبيعات والأرباح | المبيعات والمرتجعات وتكلفة البضاعة ومجمل الربح وهامشه، مجمّعة حسب اليوم أو الشهر أو المنتج أو التصنيف أو الماركة أو العميل أو الكاشير أو الفرع |
| تقرير المشتريات | المشتريات حسب المورد أو المنتج أو الشهر أو الفرع |
| تقرير المصروفات | المصروفات حسب البند والشهر والفرع |
| تقييم المخزون | كمية كل صنف وقيمته بالتكلفة وبسعر البيع، مع خيار **النواقص فقط** |
| أعمار الديون | المستحق على العملاء وللموردين مقسّمًا حسب العمر: 0–30 و31–60 و61–90 وأكثر من 90 يومًا |
| حركة الخزينة والبنوك | الرصيد الافتتاحي والوارد والمنصرف والرصيد الختامي لكل حساب، وحسب مصدر الحركة |
| قائمة الدخل | الإيرادات وتكلفة المبيعات والمصروفات وصافي الربح |
| الميزانية العمومية | الأصول والخصوم وحقوق الملكية في تاريخ معيّن |
| تقرير الضرائب | الضريبة المحصّلة من المبيعات، والمدفوعة على المشتريات والمصروفات، وصافي الضريبة المستحقة |

> تعتمد دقة التقارير على تسجيل كل العمليات في وقتها، وعلى قفل الورديات يوميًا.
